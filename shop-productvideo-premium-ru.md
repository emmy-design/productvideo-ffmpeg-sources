# «Видео товаров и акций» для Shop-Script: базовая версия и Premium

Описание относится к плагину **«Видео товаров и акций»** для Shop-Script, версия **1.0.0**, идентификатор **shop/plugins/productvideo**.

| Возможность | Базовая версия — бесплатно | Premium плагина |
| --- | --- | --- |
| Одновременно включённые размещения видео в каталоге товаров и баннерах акций | До 3 суммарно | Без лимита плагина по количеству размещений |
| Загрузка готового видео | Да | Да |
| Подготовка видео для витрины в браузере: MP4/H.264, размер кадра, частота кадров и битрейт | Да | Да |
| Предпросмотр подготовленного видео перед загрузкой | Да | Да |
| Воспроизведение видео без звука и с повтором | Да | Да |

**Основное отличие Premium — снятие общего лимита в 3 одновременно включённых размещения.** Например, видео у двух товаров в каталоге и один баннер акции занимают все три размещения базовой версии. Загрузка файла без включения показа не занимает размещение. Замена видео в уже существующем размещении не увеличивает их количество.

Лимиты размера загружаемого файла и другие ограничения сервера действуют в обеих версиях. Вывод видео в каталоге зависит от поддержки темы дизайна.

## Генерация видео с ИИ

Генерация и видеотека подключаются через отдельное приложение «Видео с ИИ» (Productvideo). Его лицензия и условия сервиса генерации действуют отдельно. Premium приложения не снимает лимит размещений этого плагина; для этого нужен **Premium плагина shop/plugins/productvideo**.

Цены и доступные условия приобретения Premium указываются в карточке плагина в магазине Webasyst.
